# 🐍 Snake Game

A classic Snake game built with Python and Streamlit.

🎮 **[Play Live Demo](https://snake-game-app-gogsezmyzmebsvvexh7pny.streamlit.app/#snake-game)**

## How to Play
Use the keyboard arrow keys to control the snake. Eat the food to grow longer and increase your score.

## Tech Stack
- Python
- Streamlit
- HTML / JavaScript (game logic)

## Run Locally
```bash
pip install -r requirements.txt
streamlit run app.py
```
